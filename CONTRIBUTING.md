# Contributing

Use Windows and the .NET 8 SDK. Open `MLStudio.csproj`, make a focused change, and run the checks described in the README before proposing a pull request.

For bug reports, describe the expected and actual behavior, Windows version, app version, and steps to reproduce. Include a small synthetic CSV when relevant. Do not include API keys, private datasets, signing certificates or Microsoft Store account files.

Keep generated build output, screenshots from test runs and executables out of commits. Required guide illustrations in `Help/Images` and published documentation in `docs/pdf` are intentional source assets.

For machine learning changes, explain effects on preprocessing, train/test separation, evaluation and reproducibility. For UI changes, include a screenshot and check the minimum window size.

Unless explicitly agreed otherwise, contributions are provided under GPL-3.0-or-later, the same license as this project.
